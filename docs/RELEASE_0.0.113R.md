## Publication layout

The source is published in `valerop/LinkEDA`. Binary files are attached to
the GitHub Release instead of committed to Git. The Quarto website links to
those immutable release assets.

The complete Windows distribution contains LinkEDA source, the exact R 4.4.2
source archive and third-party notices. The standard distribution contains the
corresponding LinkEDA source.

## macOS

`MACOS_HANDOFF.md` defines how to produce the matching macOS build from this
release without merging repository layouts or creating a nested package.
